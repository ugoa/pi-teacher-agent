Install:

* brew install fd
* pi
* tmux
* pi install git:github.com/amosblomqvist/pi-interactive-subagents
* Deepseek API key


Usage:

run `pi`


create markdown file under `topics/`

in pi console:


```
/skill:teach
<Give instructions of the topic you would like to learn>
```


Sync the session with markdown log

```
/md-log ./topics/<topic>.md
```
